# Frontend build output

This directory is generated by `pnpm build` in `web/` and copied here before `go build`.
Files are gitignored (`static/out/*`); this placeholder keeps `go:embed all:out` compiling
when the frontend has not been built.

Do not edit files here manually — run:

```bash
cd web && pnpm build && cd .. && rm -rf static/out && cp -r web/out static/out
```
